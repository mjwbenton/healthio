# Plan: Add `days` Field to `WorkoutTotal` GraphQL Type

## Context

The UI plan at `share.mattb.tech` wants to add day-by-day charts for running and strength workouts, similar to the day-level charts that exist for swimming/walking distance. The current `WorkoutTotal` type only exposes a `months` field, which limits charts to monthly granularity.

The good news: individual workouts are already stored as separate DynamoDB rows with a full ISO timestamp as the sort key. The existing monthly aggregation is done entirely in-memory in the GraphQL resolver by grouping fetched workouts by month. Adding `days` follows exactly the same pattern — no DynamoDB or ingestion changes are needed.

## Implementation Plan

### Step 1: Update `schema.graphql`

**File:** `packages/graphql-lambda/src/schema.graphql`

Add a new `WorkoutDay` type and add `days` to `WorkoutTotal`:

```graphql
type WorkoutTotal {
  count: Int!
  durationSeconds: Int!
  activeEnergyBurned: Int!
  distance: Distance
  speed: Speed
  workouts: [Workout!]!
  days: [WorkoutDay!]!      # NEW
  months: [WorkoutMonth!]!
}

type WorkoutDay {
  date: Date!
  count: Int!
  durationSeconds: Int!
  activeEnergyBurned: Int!
  distance: Distance
  speed: Speed
  workouts: [Workout!]!
}
```

`WorkoutDay` mirrors `WorkoutMonth` but uses a `date: Date!` instead of `year`/`month` int fields. It includes `workouts` for consistency with `WorkoutMonth`.

### Step 2: Update `workoutResolver.ts`

**File:** `packages/graphql-lambda/src/workoutResolver.ts`

Add a `generateDaysBetween()` helper (mirrors existing `generateMonthsBetween()`) and add `days` to the return object:

```typescript
// New helper — same pattern as generateMonthsBetween
function generateDaysBetween(from: Date, to: Date) {
  const days = [];
  let current = startOfDay(from);
  while (current <= to) {
    days.push(current);
    current = new Date(current.getFullYear(), current.getMonth(), current.getDate() + 1);
  }
  return days;
}
```

Add `days` alongside `months` in the resolver return value:

```typescript
days: generateDaysBetween(startDate, endDate).map((date) => {
  const dayWorkouts = allWorkouts.filter((workout) => {
    const workoutDate = workout.startTime;
    return (
      workoutDate.getFullYear() === date.getFullYear() &&
      workoutDate.getMonth() === date.getMonth() &&
      workoutDate.getDate() === date.getDate()
    );
  });
  return {
    date,
    count: dayWorkouts.length,
    workouts: dayWorkouts,
    ...aggregateWorkouts(dayWorkouts),
  };
}),
```

`startOfDay` is already imported in the file.

### Step 3: Regenerate GraphQL types

```bash
cd packages/graphql-lambda && yarn codegen
```

This updates `src/generated/graphql.ts` to include the new `WorkoutDay` type and `days` field.
